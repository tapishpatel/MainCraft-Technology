# MainCraft Technology — Company Website

Static website for MainCrafts (home, about, and contact pages). Built with HTML, CSS, and a small bit of JavaScript for the mobile menu and contact form checks.

## Pages

- `index.html` — Home and feature overview
- `about.html` — Company background and values
- `contact.html` — Contact form and details

## Run locally

Open any `.html` file in your browser, or use a simple local server:

```bash
npx serve .
```
